# 兵庫県学力向上研修会 配布資料

淡い青を基調にした、研修会の資料配布サイトです。PC・スマートフォンに対応しています。

## 確認方法

`index.html` をブラウザで開いてください。ビルドや外部サービスへの接続は不要です。

## 資料の追加

1. ファイルを `files/` フォルダへ入れます。
2. `index.html` 下部の `const materials = [];` に資料情報を登録します。

```javascript
const materials = [
  {
    title: '研修資料',
    description: '研修の内容をまとめた資料です。',
    type: 'PDF',
    file: 'files/material.pdf',
    size: '2.4 MB'
  }
];
```

- `type` は `PDF`、`PowerPoint`、`Word`、`Excel`、`ZIP` などを指定できます。
- `description`、`size` は省略可能です。
- 資料を追加すると検索・種類別の絞り込みが自動で表示されます。
- ファイル名は英数字とハイフンを推奨します。日本語や空白にも対応します。
- ファイルを削除・改名する際は一覧の登録内容も更新してください。

## 公開前の確認

現時点では資料未掲載の「準備中」表示です。ダミー資料は登録していません。

検索エンジン向けに `noindex,nofollow` を設定しています。これはアクセス制限ではありません。リポジトリの公開範囲やGitHub Pagesの設定は別途管理してください。

GitHub Pagesを有効にする操作は実施していません。一般公開の際はプランとリポジトリの公開範囲を確認し、必要に応じて robots メタタグを変更してください。
